# Helldivers 2 — Loadout-Builder (Stufe 1–10, alle Fraktionen)

Interaktiver Loadout-Empfehler für **Helldivers 2**: wähle Fraktion (Terminids / Automatons / Illuminate),
Schwierigkeitsgrad-Band (1–3 / 4–6 / 7–10), Spielstil (Anti-Horde / Anti-Heavy / Allrounder) und Team/Solo —
und bekommst ein durchoptimiertes Loadout mit Bildern, Begründungen und Einsatz-Tipps.

Reine statische Single-Page-App (HTML/CSS/JS), kein Build nötig.

## Hinweise
- Meta-Stand 2026 — Balance ändert sich mit Patches, als Orientierung gedacht.
- Waffen-/Stratagem-Bilder stammen aus dem Helldivers-Community-Wiki und sind Eigentum von **Arrowhead Game Studios**. Dies ist ein nicht-kommerzielles Fan-Projekt.
